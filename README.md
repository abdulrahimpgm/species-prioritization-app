## 📌 Overview
The Species Prioritization Tool is a web-based application developed using **Streamlit (Python)** to support conservation planning.  
It prioritizes plant species based on multiple ecological and socio-economic criteria.

---

## 🔬 Criteria Used
- Endemism (×3)  
- Population Size (×2)  
- Site Occupancy (×1.5)  
- Altitudinal Range (×1)  
- Habitat Specificity (×2)  
- Exploitation (×2)  
- Threat Level (×2)  

Each criterion is weighted to give a total score out of 51, which is converted to a **priority class**: Critical (>75% of maximum), High (60–75%), Medium (45–60%), Low (<45%).

---

## 🖥️ Application Features
- Bulk species prioritization using CSV upload  
- Single-species prioritization  
- Downloadable Excel reports  
- Transparent scoring criteria
